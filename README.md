# Road to 270: Election 2028

**Road to 270** is a browser-based political strategy game in which players choose a candidate, build a national campaign, manage resources, track polling, and compete for the 270 electoral votes needed to win the 2028 United States presidential election.

## Play now

**[Launch the public game](https://road-to-270-2028.josephc148.chatgpt.site)**

The current release is an early public alpha. Feedback, balance suggestions, bug reports, and contributions are welcome.

## Current features

- Eight playable public-figure candidates with different strengths and resources
- Fourteen campaign turns leading to Election Day
- Speeches, town halls, fundraising, door knocking, advertising, policy launches, debate preparation, opposition research, and candidate recovery
- Campaign funds, political capital, momentum, energy, volunteers, and debate-readiness systems
- National and battleground-state polling tracker
- State targeting and projected Electoral College paths
- Animated campaign-rally scenes with optional audio
- A compressed 78-second election-night broadcast
- Live state calls, vote totals, reporting percentages, and electoral-vote counters
- Purple alerts and animations when a state flips against its pre-election lean
- Local browser saves and replay support

## Run locally

Requirements:

- Node.js 22.13 or newer
- npm

```bash
npm install
npm run dev
```

Then open the local address shown in the terminal.

## Important disclaimer

Road to 270 is a fictional, unaffiliated political strategy game created for entertainment. Public figures represented in the game have not endorsed, sponsored, or participated in the project. Candidate ratings, fictional opponents, campaign events, dialogue, polling, and election outcomes are invented gameplay elements and should not be treated as factual predictions or statements.

## Contributing

Before submitting a change:

1. Open an Issue or Discussion describing substantial proposed work.
2. Keep pull requests focused on one feature or fix.
3. Test the complete campaign and election-night sequence.
4. Use only original, generated, public-domain, or appropriately licensed assets.
5. Avoid defamatory content, official campaign branding, and television-network branding.
